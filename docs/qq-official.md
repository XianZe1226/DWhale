# QQ 官方机器人首次使用

DWhale 通过 QQ 开放平台的 WebSocket 接口接收消息。Windows、macOS 和 Linux 使用相同的设置流程。

## 准备机器人

1. 在 QQ 开放平台创建机器人，或使用已有机器人。按平台当前页面完成开发者资格、安全校验和可用场景配置。
2. 在「开发设置」获取 AppID 与 AppSecret。若平台要求沙箱测试用户、使用范围或 IP 白名单，先完成这些配置。
3. 确认机器人具备消息列表单聊能力。聊天入口、上线审核与可用范围以该机器人的管理页为准。

平台申请流程与权限可能调整，具体参照 QQ 开放平台和 AstrBot 官方接入指南。[QQ 开放平台](https://q.qq.com/) · [AstrBot 官方指南](https://github.com/AstrBotDevs/AstrBot/wiki/zh-platform-qqofficial-websockets)

## 连接 DWhale

1. 打开 DWhale，在「环境」完成运行环境准备。
2. 进入「QQ 连接」，点击启动，再打开「配置官方机器人」。
3. 在内置 AstrBot 控制台的「机器人」页面创建 **QQ 官方机器人（WebSocket）**，填写 AppID 和 AppSecret。
4. 开启「启用」与「消息列表单聊」，保存配置。平台 ID 用于后续绑定，应保持固定。
5. 按开放平台提供的聊天入口进入与机器人的私聊。

首次打开内置控制台时，用「控制台首次口令」完成登录并设置密码。已有控制台沿用原密码。AppSecret 只填写在本机控制台，截图、反馈和公开配置中应移除它。

WebSocket 连接由运行 DWhale 的电脑向外建立。白名单如有要求，应填写实际网络出口地址，网络出口变化后需在平台核对。

对话服务运行时，如果网络短暂中断或心跳超时，DWhale 会自动重连。QQ 需要人工处理接入时，连接页会提示检查官方配置。电脑休眠期间服务会暂停，系统唤醒、网络恢复后可以继续连接。

## 绑定主人

1. 在 QQ 消息列表私聊中发送下列命令。

   ```text
   /fish whoami
   ```

2. 复制回复中的完整「本会话」。格式如下。

   ```text
   平台ID:FriendMessage:官方用户标识
   ```

3. 在 DWhale「QQ 连接」的「官方机器人私聊会话 ID」中粘贴并保存。
4. 配置聊天模型后，在同一私聊发送「你好」，再用 `/fish status` 核对绑定状态。

OpenID 区分大小写。应用同时核对适配器、平台实例和已经收到的 C2C 私聊记录。主人专属人格、视频任务和主动互动作用于这条已绑定的私聊。

## 模型、记忆与视频

在「模型与记忆」添加聊天模型，需要图片理解时配置图片模型。长期记忆需选择 Embedding 模型、整理模型及正确的会话作用域。已有索引应继续使用原 Embedding 模型和维度。[配置指南](setup.md)

B站功能在 B站页面单独配置。可先发送 `/fish watch <视频链接>` 验证视频理解，再启用主动选题与推荐。[B站指南](bilibili.md)

## 主动消息

绑定私聊并配置好聊天模型后，在「QQ 连接」打开「主动找你聊」并保存。新配置默认在最后一条消息后随机等待 30–75 分钟，每天最多发起 3 次。开启「没回复也偶尔来聊」，即使未收到回复，鱼仍会按间隔和每日上限找你聊。关闭该开关时，连续两次没回复就等你先开口。间隔和每日次数可在 AstrBot 的 DWhale 插件配置中调整。

想让鱼自己拿主意时，打开「随心找我聊」。它用当前聊天模型参考近期的私聊文字、已启用的日记记忆和角色心情，决定现在开口还是过一会儿再想。这个模式没有 DWhale 的每日次数或未回复次数上限，仍遵守免打扰、暂停和 QQ 官方发送规则。角色的近期心情和念头保存在本机，重启后可继续。用 `/fish status` 查看目前状态。

在「哔哩哔哩」单独设置看视频的作息和推荐渠道。视频发现和分享使用自己的额度。用 `/fish status` 查看聊天等待原因、聊天次数和视频次数。

聊天次数统计已发起的尝试。连续未回复在一次主动聊天首次提交给 QQ 时增加。主动聊天和视频推荐受 QQ 消息权限约束，无法确认送达时显示「未确认」。

电脑休眠、断网或关闭服务后，后台活动会暂停。建议先完成普通私聊的收发，再逐项开启主动功能。平台配额与可用范围以机器人当前权限及实际返回为准。[AstrBot 官方指南](https://github.com/AstrBotDevs/AstrBot/wiki/zh-platform-qqofficial-websockets)

## 晚上写日记

在「QQ 连接」开启「晚上写日记」。服务运行时，DWhale 按插件设置的时区在 23:00 整理上一自然日中你在绑定私聊发来的文字，保存日记和关键记忆。启用后才开始收集文字，原有聊天记录无需迁移。整理使用该私聊配置的聊天模型，结果写入本机数据目录。近期提取的记忆会为这条私聊提供对话参考。

发送 `/fish diary` 查看最新日记，或发 `/fish diary 2026-11-18` 查看指定日期。错过 23:00 时，服务恢复后会尝试最近一次尚未完成的回顾。没有资料的日期会跳过。

## 从旧个人 QQ 接入升级

升级前保存一份本机私有备份。新版本会在安装、恢复与服务启动前停用旧个人 QQ 协议平台，并归档相关旧字段。

模型供应商、人格、会话和记忆文件继续保留。官方 OpenID 是新的身份，需要重新完成上述绑定。旧私聊记录和待投递任务保留原接收者，跨身份记忆需要用户核对作用域后使用 LivingMemory 的导入或迁移功能处理。

旧版应用应先正常退出，再覆盖安装新的官方接口版。历史独立协议组件的账号数据可能仍留在原私有目录，可在备份并确认后自行清理。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 无法进入私聊 | 在开放平台核对消息列表单聊、测试用户、使用范围和聊天入口。 |
| 保存绑定失败 | 从实际消息列表私聊重新发送 `/fish whoami`，复制完整会话 ID。 |
| 配置已保存，仍在等待连接 | 核对平台启用状态、凭据、网络出口和白名单要求。 |
| 已连接，但没有模型回复 | 检查模型供应商、具体模型、余额和工具调用支持。 |
| 主动消息未收到 | 检查免打扰、预算和平台权限，并查看「未确认」记录。 |
| 希望修改个人 QQ 签名或发空间 | 当前产品仅提供官方机器人消息能力。 |
